# Расписание КИТиС

Расписание занятий ГБУ КО ПОО «Колледж информационных технологий и строительства».
Данные в реальном времени берутся с официального сайта расписания
**http://94.72.18.202:8083** («Экспресс-расписание», windows-1251) и разбираются на сервере.

**Живая версия:** https://0x-dorothy.github.io/kitis-sched/

## Возможности

- **Расписание групп, преподавателей, аудиторий** — переключатель типа + поиск по списку
- **Два вида**: «доска» (недельная сетка) и «список» (в столбик по дням), переключаются и запоминаются
- **Таймер пары** — в шапке всегда видно: до конца пары, перемена, начало занятий, выходной
- **Избранное** — звёздочка у группы/преподавателя/аудитории; у гостей в браузере, у аккаунтов — в облаке
- **Темы** — светлая и тёмная монохромные, «Классика КИТиС» (синий/оранжевый/жёлтый как на сайте-источнике) и свой акцентный цвет
- **Прошлые и будущие недели** — архив включается после подключения базы
- **Сравнение** — до четырёх расписаний рядом, с корректной таблицей и прокруткой на телефоне
- **Звонки** — понедельник (кураторский день) и вт–сб, с подсветкой текущей пары
- **Преподаватели** — поиск, контакты, кураторство
- **Мобильная версия** — нижняя навигация, список по умолчанию, без горизонтальных перекосов

## Стек

- Next.js 16 (App Router, TypeScript, Turbopack) + Tailwind CSS 4
- Парсер: cheerio + TextDecoder(windows-1251) — только на сервере (у источника нет CORS)
- БД (опционально): Postgres (Neon) — аккаунты, избранное в облаке, архив недель
- Авторизация: bcryptjs + JWT (jose) в httpOnly-cookie
- Деплой: Vercel + GitBook + ежедневный cron-снапшот (Github Actions)


## Telegram (Mini App)

Бот: **@kitis_sched_bot**. Кнопка «Расписание» внизу чата открывает это же приложение внутри Telegram
(SDK лежит локально в `public/telegram-web-app.js`, тема и кнопка «назад» подхватываются автоматически).

Уведомления о новых неделях:
- переменная `TELEGRAM_CHAT_ID` — заполняется сама после первого `/start`
  (воркфлоу `telegram.yml` опрашивает бота каждые 5 минут);
- отправка — шаг «Notify Telegram» в `snapshot.yml`, только когда данные реально изменились.

## Архив недель

Каждая неделя, пока она актуальна, сохраняется в `public/data/archive/{id}/{week}.json`
(до 12 недель). Прошлые недели открываются стрелками ←, будущие показывают,
что расписание ещё не опубликовано на сайте колледжа.

## Архитектура

```
lib/
  source.ts            # загрузка страниц источника (windows-1251), метка «Обновлено»
  parser.ts            # cheerio: справочники + таблицы расписания (включая подгруппы)
  schedule-service.ts  # живой парсинг + снапшоты недель в БД + полная синхронизация
  bells.ts             # звонки (Пн — кураторский день, Вт–Сб — основное)
  weeks.ts             # недели и даты в таймзоне колледжа (Europe/Kaliningrad)
  theme.tsx            # темы: схема (light/dark/system) + пресеты акцента
components/
  header.tsx           # шапка, таймер, меню тем, мобильная навигация
  schedule-view.tsx    # доска и список
  entity-picker.tsx    # тип + поиск
app/api/
  directory · schedule · auth/* · favorites · cron/sync
```
