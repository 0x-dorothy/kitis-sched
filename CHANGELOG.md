# Изменения

## 2026-11-08 — уведомления от бота убраны

- Бот **@kitis_sched_bot** больше не присылает сообщений: ни рассылок об обновлении
  расписания, ни ответов на команды. Из чата доступна только кнопка **«Расписание»**,
  которая открывает мини-приложение.
- Удалены шаг «Notify Telegram» в `snapshot.yml`, скрипты `scripts/notify.ts`
  и `scripts/bot-poll.mjs`, воркфлоу `telegram.yml`.
- Данные по-прежнему обновляются каждые 30 минут, просто молча.

## 2026-11-08 — мини-приложение Telegram и архив недель

- Добавлен Telegram Mini App: SDK подключён локально, тема и кнопка «назад»
  берутся из Telegram, есть вибрация на избранное.
- Настроена кнопка меню бота, открывающая сайт.
- Недели: прошедшие открываются из архива (до 12 недель, все типы),
  будущие показывают «расписание ещё не опубликовано».
- Убраны все упоминания базы данных из интерфейса.

## 2026-11-08 — переезд на GitHub Pages

- Сайт стал статическим (Next.js `output: export`) и живёт на GitHub Pages:
  https://0x-dorothy.github.io/kitis-sched/
- Данные собираются парсером в GitHub Actions каждые 30 минут и коммитятся в `public/data`.
- Убраны аккаунты и серверные API: избранное хранится в браузере,
  `/profile` стал страницей настроек (тема + избранное).
- Проекты на Vercel удалены.

## 2026-11-07 — редизайн

- Новая дизайн-система: монохром, волосяные линии, табличная типографика, линейные иконки.
- Темы: светлая / тёмная / системная + пресеты «Монохром», «Классика КИТиС»
  (синий/оранжевый/жёлтый как на сайте-источнике) и свой акцентный цвет.
- Два вида расписания: «Список» и «Доска».
- Таймер пары закреплён в шапке и виден всегда.
- Исправлено переключение групп / преподавателей / аудиторий.
- Переписано сравнение расписаний: ровные колонки, прокрутка на телефоне.
- КИТиС вместо КИПиС, логотип колледжа в шапке и иконке сайта.
